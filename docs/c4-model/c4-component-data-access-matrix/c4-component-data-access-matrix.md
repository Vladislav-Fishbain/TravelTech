\# C4 Component Data Access Matrix (CRUD)



Матрица разграничения ответственности и доступа микросервисов к таблицам центральной базы данных PostgreSQL.



| Компонент / Сервис | Таблицы БД (PostgreSQL) | Тип операции | Обоснование бизнес-логики |

| :--- | :--- | :---: | :--- |

| \*\*API Gateway\*\* | `trips`, `trip\_members` | \*\*C\*\* | Создание новой поездки и автоматическое связывание участников (`POST /api/v1/trips`) |

| \*\*Booking Service\*\* | `passport\_data`, `itinerary\_items` | \*\*C, U\*\* | Первичное добавление броней и паспортов; обновление статуса на `confirmed` при получении платежного вебхука |

| \*\*Trip Service\*\* | `itinerary\_items`, `passport\_data`, `trips` | \*\*R, C, U\*\* | Идемпотентная запись офлайн-изменений из кэша (`/sync`), чтение паспортов группы для экстренного перебронирования альтернатив |

| \*\*RecEngine (Альфред)\*\* | `itinerary\_items`, `user\_profiles`, `alternative\_options` | \*\*R, C\*\* | Анализ конфликтов расписания, проверка ограничений по визам/багажу, сохранение просчитанных вариантов на замену |

| \*\*Notification Service\*\* | `notifications`, `user\_profiles` | \*\*C, U\*\* | Сохранение лога отправленных уведомлений, агрегация входящих оценок и отзывов (`POST /api/v1/feedback`) в профиль |

| \*\*Cron Worker\*\* | `passport\_data`, `trips` | \*\*U, D\*\* | Автоматическое удаление персональных данных (паспортов) спустя 24 часа после поездки, перевод статуса поездки в `completed` |



\*\*Условные обозначения:\*\*

\* \*\*C\*\* (Create) — создание записей (INSERT).

\* \*\*R\*\* (Read) — чтение данных (SELECT).

\* \*\*U\*\* (Update) — обновление данных (UPDATE).

\* \*\*D\*\* (Delete) — удаление данных (DELETE).
